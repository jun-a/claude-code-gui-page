Gemini CLI

An open-source AI agent that brings the power of Gemini directly into your terminal.

npm install -g @google/gemini-cli

Free Tier

Get started with a generous free tier, offering 60 requests per minute and 1,000 per day.

Powerful Model

Access the power of Gemini 1.5 Pro with a 1 million token context window for complex tasks.

Built-in Tools

Includes Google Search grounding, file operations, shell commands, and web fetching.

Extensible

Integrate with custom tools and services using the Model Context Protocol (MCP).
